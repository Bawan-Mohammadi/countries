# 🌍 Countries App

This app fetches and displays country data from an external API using async/await.  
It helped me understand asynchronous JavaScript, working with APIs, and handling errors.

## Features
- Fetch country data from API  
- Display country details dynamically  
- Async/await for API calls  
- Basic error handling

- HTML 
- CSS 
- JavaScript
